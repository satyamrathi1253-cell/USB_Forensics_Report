# USB Forensics Report 

## Project Overview 

This project demonstrates the basic forensic examination of a USB flash drive. The objective was to collect and document evidence without modifying the original data. 

## Objectives 

- Identify the USB device
- Document forensic evidence
- Examine file system information
- Verify partition status
- Prepare a professional forensic report

## Tools Used 

- Windows File Explorer
- Device Properties
- Disk Management
- Microsoft Word

## Evidence Details

- Device: HP USB Flash Drive
- Label: New Volume
- Capacity: 117.19 GB
- File System: NTFS
- Status: Healthy (Primary Partition)
